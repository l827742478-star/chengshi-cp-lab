# 城里遇见你｜城市 CP 匹配测试

一个原创的“性格 × 城市 × CP”趣味测试网页，纯静态 HTML/CSS/JS，无需安装依赖。

## 打开方式

直接双击 `index.html`，或在该目录运行任意静态服务器，例如：

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 已包含

- 首页城市轨道视觉与测试入口
- 8 道直觉题、进度条、上一题
- 4 种原创城市人格结果
- 主场城市 × 心动 CP 匹配卡
- 结果文案复制分享、重新测试
- localStorage 保存最近一次结果
- 移动端布局、键盘焦点、减少动态效果支持
